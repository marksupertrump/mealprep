# MealPrep

Piano alimentare settimanale, lista della spesa ottimizzata, tracker e reminder. Gira interamente nel browser (nessun server):
i dati restano sul dispositivo. Le ricette **non** sono incluse: si importano da file (scheda *Dati*).

Installabile da Chrome (Aggiungi a schermata Home) e funziona offline dopo la prima apertura.
